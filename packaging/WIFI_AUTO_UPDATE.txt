WI-FI / TAILSCALE AUTO-UPDATE — Traffic Deployer
================================================

When the work laptop is on Tailscale, the home PC can serve an AppUpdate
and the laptop pulls it. Home Wi-Fi is not required.

HOME PC (this machine)
----------------------
1. BUILD_WIFI_UPDATE.bat     (or BUILD_APP_UPDATE.bat then PUBLISH_APP_UPDATE.bat)
2. UPDATE_LAPTOP.bat         — starts the server on Tailscale 100.x + LAN
   (or C:\TDReleases\SERVE_RELEASES.bat if the server is all you need)
3. Leave the server running until the laptop finishes downloading (~300 MB)

WORK LAPTOP
-----------
Tailscale connected (orange/green). Then either:

- OPEN_APP.bat while the home server is up — app checks version.json and applies
- WIFI_UPDATE_NOW.bat — one-click pull + apply even if the app is closed

First successful update also registers a 15-minute poller
(TrafficDeployerTailscaleUpdate) so later releases apply while the laptop
is on Tailscale and the app is closed.

HOW UPDATE RUNS
---------------
- App reads version.json, downloads zip, replaces exe + _internal + web
- tds_data\ is never touched; app restarts on new version
- Downloads overwrite one slot (tds_data\update_staging)
- Home server keeps one zip: C:\TDReleases\TrafficDeployer-AppUpdate.zip
- Channel lists Tailscale MagicDNS + 100.x + LAN so the laptop uses whichever answers

EACH NEW RELEASE
----------------
1. Home: BUILD_WIFI_UPDATE.bat
2. Home: UPDATE_LAPTOP.bat
3. Laptop: OPEN_APP.bat or WIFI_UPDATE_NOW.bat (or wait for the poller)
4. Laptop title bar must show the new version number

TROUBLESHOOT
------------
- "Could not reach update server" -> UPDATE_LAPTOP.bat running? Tailscale connected?
- "No update channel" -> run OPEN_APP.bat or WIFI_UPDATE_NOW.bat once
- "version.json missing download_url" -> UTF-8 BOM; re-run PUBLISH_APP_UPDATE.bat
- Field mode in the app still updates if you launch via OPEN_APP.bat (TD_UPDATE_HOME set)
- Poller skips while TrafficDeployer.exe is running (won't interrupt a shift)

USB STILL WORKS
---------------
dist\TrafficDeployer-AppUpdate-VERSION.zip manual copy — see APP_UPDATE.txt
(example: TrafficDeployer-AppUpdate-1.0.12.zip)
