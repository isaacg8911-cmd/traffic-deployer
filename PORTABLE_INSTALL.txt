Traffic Deployer — portable install (work laptop)
===============================================

Requirements on the laptop:
  - Windows 10/11
  - Python 3.10+ installed (python --version in cmd)
  - Internet on first run (venv + California map download)

Steps:
  1. Unzip anywhere (e.g. C:\TrafficDeployer)
  2. Double-click START.bat
  3. First run: installs .venv, pip packages, downloads offline map (~1.4 GB, 10–20 min on WiFi)
  4. App opens — use Setup → Field Readiness to confirm green

Optional — skip map download on work laptop:
  Copy the whole tds_data folder from your home PC into the unzip folder
  (includes california.pmtiles + road graph if you built routes at home).

Field use:
  - Load real Excel + .EST (or demo_data for desk test)
  - Download road map → BUILD ROUTE → READY FOR OFFLINE
  - Voice: Route tab → Test voice (Windows Zira / female SAPI)

Version: 1.0.4 — see About in app.
