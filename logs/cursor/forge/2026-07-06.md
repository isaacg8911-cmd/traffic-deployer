## [Cursor Log] Max-zoom map whitens out — DEMAND

**Symptom:** Last zoom-in step paints a blank/light map.

**Root cause:** `california.pmtiles` header `maxZoom` is **15**, but style/app were bumped to display zoom **16**. MapLibre requested z16 tiles; PMTiles returned empty MVT bytes; MapLibre did not overzoom z15 → only background `#f4f3ee` visible.

**Fix:**
- `web/style.js` — `TILE_MAX_Z = 15` on vector source; keep `MAX_Z = 16` for paint interpolation / UI headroom (overzoom).
- `web/app.js` — `pmtiles.Protocol({ errorOnMissingTile: true })` so missing tiles error → overzoom fallback.
- `setup_maps.py` — vendor pin `pmtiles@4.1.0` (has `errorOnMissingTile`).
- `scripts/smoke_full.py` — checks for tile/source alignment.

**Optional sharper z16:** re-run `python setup_maps.py` (wifi), then set `TILE_MAX_Z = 16` in `style.js`.

**Proof:** disk header bytes 100–101 → minZoom 0 maxZoom 15; targeted web asset checks pass.
