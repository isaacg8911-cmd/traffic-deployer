Traffic Deployer — Wi-Fi update

Same home Wi-Fi as the home PC. No USB.

Do this (easiest) 1. Close Traffic Deployer if it is open.
2. Download the green button.
3. Double-click the downloaded file.
4. Wait (~300 MB). Black window shows progress.
5. App reopens — title must show 1.0.13 (or newer).
Download WIFI_UPDATE_NOW.bat
Optional: normal launcher Download OPEN_APP.bat

If download fails: home PC update server is off, or laptop is on a different Wi-Fi.
