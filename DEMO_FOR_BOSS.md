# Traffic Deployer — 5-minute demo (boss / coworker)

**Private:** runs on your laptop only (`localhost`). No cloud account required.

## Before the room (2 min)

1. Run **`SMOKE.bat`** once (green = dependencies + map assets OK).
2. Plug in **USB GPS** (BU-353N), wait for sky view.
3. Double-click **`START.bat`** — app opens to California map.
4. Have one real **Excel + .EST** pair ready, or use **Setup → Load demo files**.

## Demo script (5 min)

| Step | Say | Do |
|------|-----|-----|
| 1 | "This is our field route tool — offline, on real streets." | Show map + **Setup** tab |
| 2 | "We load the week's sites and map files from Excel." | Choose files (or **Load demo files**) → **Download road map** if needed → **BUILD OPTIMIZED ROUTE** |
| 3 | "Stops are ordered to cross lines efficiently; path follows roads." | **Route** tab — scroll stops, show mile total |
| 4 | "Driver mode — live GPS, voice, one stop at a time." | **START DRIVING** — move map / show follow |
| 5 | "Install records serial, direction, GPS at the pole." | **Install** — Grab GPS → INSTALL on one stop |
| 6 | "End of week — audit catches gaps, exports Excel." | **Audit** → export preview |

## If something breaks

- Restart: close app → **`START.bat`** again.
- Smoke proof: `SMOKE.bat` (Forge runs before demo day).
- Full doc: `HOW_TO_RUN.md`

## Out of scope for this demo

Cloud hosting, multi-user login, non-California regions.
