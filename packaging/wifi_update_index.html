Traffic Deployer — Wi-Fi update setup

Do this once on the work laptop (same home Wi-Fi as the home PC). No USB.

Step 1 — Download the channel file Tap the green button. Save the file as
C:\TrafficDeployer\tds_data\update_channel.json
(If Windows asks, choose Save As and go to that folder.)
Download update_channel.json
Step 2 — Open the app online Close Traffic Deployer if it is open.
Open C:\TrafficDeployer → double-click OPEN_APP.bat.
At the top of the app, make sure it says ONLINE (if it says OFFLINE, tap I'm online).
Step 3 — Wait for the popup A box should say an update was found (~300 MB).
Wait — the app closes, updates, and reopens.
Window title must show the new version (not 1.0.12).

Home PC must leave the update server running. If this page will not load, the home PC server is off.
